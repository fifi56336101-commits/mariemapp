Guide complet pour utiliser Escare efficacement

🚀 Commencer 📸 Analyse de Plaie 📋 Journal 💬 Assistant IA 🔔 Rappels
🚀

Bien Commencer

1

Installation

Téléchargez Escare sur l'App Store (iOS) ou Google Play (Android). L'application nécessite iOS 13+ ou Android 8+.

📷 Caméra 🖼️ Photos 🌐 Internet
2

Configuration du Compte

Créez un compte avec votre email ou continuez en tant qu'invité. Le mode invité stocke les données localement sur votre appareil.

  • Inscription Email: Accès complet avec sauvegarde cloud
  • Mode Invité: Démarrage rapide, stockage local uniquement
3

Sélection de la Langue

Choisissez votre langue préférée dans les Paramètres. Langues disponibles :

🇬🇧 English
🇫🇷 Français
🇸🇦 العربية
🇪🇸 Español
📸

Analyse de la Plaie

1

Informations Patient

Saisissez les données cliniques pour une analyse précise :

🎂 Âge: Âge du patient en années
⚠️ Facteurs de Risque: Diabète, mobilité
📍 Localisation: Site anatomique
⏱️ Durée: Temps depuis le début
😣 Niveau Douleur: Échelle 1-10
🦠 Signes Infection: Rougeur, chaleur, pus
2

Capturer l'Image

Prenez une photo claire de la plaie :

  1. Assurez un bon éclairage
  2. Positionnez la caméra directement au-dessus
  3. Incluez la peau environnante
  4. Gardez la caméra stable
💡 Conseil : Utilisez un éclairage et des angles constants pour un meilleur suivi.
3

Résultats d'Analyse

L'IA fournit une analyse complète :

  • Urgence: CRITIQUE, ÉLEVÉE, MOYENNE, FAIBLE
  • Stade: 1-4, Inclassable, DTI
  • Description: Caractéristiques de la plaie
  • Risque Infection: Faible, Moyen, Élevé
  • Recommandations: Instructions de soins
⚠️
Avertissement Médical

Cette analyse par IA est à titre éducatif uniquement. Consultez toujours un professionnel de santé pour les décisions cliniques.

📋

Journal des Plaies

💾

Sauvegarder les Analyses

Après chaque analyse, appuyez sur "Sauvegarder dans le Journal" pour stocker les résultats avec l'image, l'analyse et l'horodatage.

📊

Voir l'Historique

Accédez à votre journal depuis l'accueil. Consultez la chronologie, les statistiques et comparez les entrées.

📈

Suivre le Progrès

Surveillez la guérison en comparant les entrées. Suivez les changements de stade, la taille et l'efficacité des interventions.
